# 费率 / 锁定 / 摩擦怎么核（Fee & Friction Audit）

> 目标：把"能不能随时动、动了要花多少钱"算清楚。不产出"换哪只"，只产出"这只的摩擦账"。

## 一、申购费核验

- 是否为 0？很多 C 类申购费为 0，但有销售服务费（年化，从净值扣）。
- 是否有起购门槛（如 50 万起、1 元起）？门槛高的品种小资金买不进。
- 是否限购 / 暂停申购？排名再好、买不进就是无效候选。

## 二、赎回费分档核验（最关键）

C 类普遍有**惩罚性赎回费**，能赎 ≠ 免费赎。必须逐档列出：

| 持有期 | 常见费率 | 备注 |
|---|---|---|
| < 7 天 | 1.50% | 监管强制，所有 C 类一致 |
| 7–30 天 | 0% 或 0.10% | 各基金差异大，必须逐只看 |
| ≥ 30 天 | 0% | 部分产品仍要 60 天 |
| ≥ 60 天 | 0% | 少数长久期产品 |

**判断原则**：按使用者"随时可能动用"的优先级选——满 7 天即零赎回费的品种，摩擦最小；要满 30 天才免费的，只在确定长持时才划算。

## 三、锁定期三层交叉验证（不能只看一个字段）

只用「最短持有期 = 空」证明无锁是**不可靠的**——定期开放基金在该字段也是空。

必须三层交叉：

1. **运作方式字段**：是否"定期开放"、是否带固定封闭期。
2. **申赎状态字段**：是否"开放赎回"、"仅开放期可赎"。
3. **公告 / 合同 / 平台页面**：基金公司"开放日常申赎"公告、产品资料概要、销售平台申赎标识。

| 类型 | 最短持有期字段 | 真实情况 |
|---|---|---|
| 普通开放式 | 空 | 无锁，每交易日可赎 |
| 定期开放（如半年定开） | **空** | 锁一个周期，仅开放期可赎 |
| 最短持有期（如 7 天） | 0.23 月左右 | 锁 7 天，期间不能提交 |
| 滚动持有（30/60/90 天） | 有值 | 每笔份额滚动锁定 |

**结论写法**：三层都指向"开放赎回"才能写"无锁"；任一层存疑，写"存疑，需使用者在 App/合同确认"。

## 四、投向穿透（识别"伪债基"）

核对接投范围，判断本金风险：

- 只投国债 / 政策性金融债 / 央行票据 → 准主权，信用风险极低，但久期可能较长、利率波动大。
- 投 AA+ 及以上信用债 / 企业债 / 短融 / 中票 / ABS → 有信用敞口与信用下沉风险。
- **混合一级债基**（含转债）→ 净值会随转债波动。
- **混合二级债基**（含股票）→ 本质是"藏了股票的债"，下跌市里最坑，必须显著提示。

## 五、摩擦成本公式

```
单次换仓摩擦 = 赎回费 + 申购费 + 在途机会成本
赎回费 = 赎回金额 × 对应持有期档位费率
在途成本 ≈ 赎回金额 × 年化收益 × (在途自然日 / 365)
```

场外机制提醒（必须写进输出）：
- 15:00 前提交按当日净值，15:00 后按次日净值。
- T+1 确认，赎回款 T+1 / T+2 到账，在途 1–2 天不计收益。
- 跨基金公司不能转换，只能"赎回 → 到账 → 申购"。

## 六、输出样例（方法论表述，非推荐）

```
【费率核验】标的 X：申购费 0 | 赎回费 <7天 1.5% / 7–30天 0.1% / ≥30天 0 | 无锁（三层验证通过）
【投向】只投国债/政金债，无信用下沉；久期 0–3 年，波动高于中短债
【摩擦账】按 X 万元、持有 20 天赎回算：赎回费 = X万 × 对应档位费率 + 在途机会成本
【辨析】若资金需随时抽调，7–30 天的 0.1% 是真实摩擦；确定放满 30 天才免费
【边界】以上为方法论与数据整理，不构成投资建议；最终决策与风险由使用者自行承担，数据以自行核实为准。
```
