# 规则闸：入场 / 卖出 / 时点（Signal Gates）

> 目标：把"现在能不能动"变成可观测、可复核的闸门。只输出闸门状态，不输出"买哪只、买多少"。

## 一、入场三信号（默认示例，使用者可自定义阈值）

三个信号都要满足，缺一不可：

| 信号 | 默认阈值 | 取数口径 |
|---|---|---|
| 成交额 | ≥ 1.55 万亿 | 全市场当日成交额，与历史同口径比较 |
| 上涨占比 | 连续 2 日 > 50% | 收盘上涨家数 / 总家数 |
| 涨停 / 跌停 | 涨停 > 跌停 2 倍 | 当日收盘涨跌停家数 |

**用法**：这三个是示例阈值，不是普适真理。使用者应替换为自己的参数，并写在配置文件里（见 `scripts/calc.py gate --config`）。

## 二、三条执行铁律

1. **必须收盘确认**。盘中值不算数——盘中 56% 到收盘可能掉到 48%。这正是"连续 2 日"规则要过滤的"盘中好看、尾盘变脸"。
2. **场外下单链路**：收盘核信号 → 作为**下一交易日**决策依据 → 下一交易日 15:00 前提交。
   - 反例（禁止）："15:00 收盘后核完信号，今天下单"——场外当天窗口已关。
3. **信号重新计时**：任一信号失败，连续计数从下一交易日**归零重算**；不因单日反弹重启，不因"跌得多"提前。

## 三、卖出闸

减仓/清仓前先过 `reasoning-chain.md` 的卖闸三问，再看：

- 是否跌破自定的减仓观察线（使用者自定义点位）？
- 是否刚经历 -20%+ 急跌（避免在恐慌低点执行）？
- 事件风险（如宏观数据公布）是否将在 48 小时内落地？

## 四、事件风险与现金管理

- 重大宏观数据/议息会议落地前，保留至少 1/3 现金子弹。
- 闲置资金停泊需满足：无锁定期、申购费 0、投向无信用下沉；收益率高低是次要考量。
- 7 天锁定的产品要单独标注**可动用日**，避免信号确认当天钱还在锁定期。

## 五、判定流程

1. 取当日收盘数据（成交额、上涨家数、涨停/跌停家数）。
2. 运行 `scripts/calc.py gate`：

```bash
python scripts/calc.py gate --turnover 1.60 --breadth-today 0.55 --consecutive-days 1 \
  --limit-up 100 --limit-down 20
```

3. 输出三个闸的达标状态 + 总体结论（全达标 / 未达标 / 待确认）。
4. 若全达标，输出的是"下一交易日可进入决策流程"，**不是"买入指令"**。

## 六、输出样例（方法论表述，非推荐）

```
【信号】成交额 X.XX 万亿 ✅ | 上涨占比 YY%（连续第1日，昨 ZZ%）🟡 | 涨停 AA:跌停 BB ✅
【判定】2/3 达标，广度第2日待收盘确认 → 今日不进入决策流程
【时点】场外 15:00 截止；若明日确认，最早下一交易日下单
【事件】宏观数据 48 小时内落地 → 保留 ≥1/3 现金
【边界】以上为方法论与数据整理，不构成投资建议；最终决策与风险由使用者自行承担，数据以自行核实为准。
```
