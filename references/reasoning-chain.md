# 推理链模板（Reasoning Chain）

> 目标：把"怎么得出结论"显式化，让使用者能看到证据、反证、成本和失效条件。结论留在最后一步，且只到"倾向/条件"，不到"买哪只、买多少"。

## 一、六段式模板（每次判断按此顺序写）

1. **现状事实**：持有/候选的客观状态（金额、占比、收益、回撤、费率、锁定）。只写数据，不写观点。
2. **数据证据**：支持某个方向的可核验证据（同源同池排名、信号状态、基本面/估值、宏观事件时点）。
3. **为何考虑**：正向逻辑——为什么值得关注/保留/调整。
4. **反证 / 风险**：反对逻辑——什么数据否定它、什么情景下会亏、久期/信用/情绪风险。
5. **摩擦成本**：申赎费、锁定机会成本、在途成本、择时错误的百分点代价。
6. **置信度与失效条件**：给"高/中/低"，并明确写出"出现什么情况这个判断作废"。

**硬性要求**：第 4 段（反证）不得省略。只给多头理由不写反证，视为未完成。

## 二、卖闸三问（减仓/清仓前必须逐条回答）

1. **是否破坏了自定逻辑？** 当初买入/持有的理由是否已被数据证伪？
2. **是否刚经历 -20%+ 急跌？** 恐慌低点卖出，往往卖在阶段底部。
3. **是否情绪驱动？** 是规则触发，还是"看别人说""感觉要跌"？

三问任一回答为"是/是/情绪驱动"→ 暂停操作，等一个交易日复核。

## 三、仓位与金额的方法（不套固定模板）

- **禁止固定金额模板**：不得默认"每次 1000 元"或"目标 5 万"。
- **买入金额与目标仓位**须结合：大盘位置、标的基本面/估值、预计持有期、使用者可承受亏损，独立判断。
- **分批纪律**：强仓回踩加仓 / 弱仓反弹减仓；每批约 1/3 子弹，保留后手。
- **场外时点**：15:00 净值截止；收盘后核的信号只能作为**下一交易日**决策依据，不能当天补单。
- **永远留后手**：事件未落地前保留至少 1/3 现金。

## 四、巴菲特参照系（必须辨析，不盲信）

按使用者要求以巴菲特框架为参考，但每次都要写出辨析：

| 概念 | 可取之处 | 必须辨析的边界 |
|---|---|---|
| 能力圈 | 只做看得懂的标的 | 行业主题指数不等于"懂"，别把赛道叙事当能力圈 |
| 安全边际 | 价格低于内在价值才买 | 高波动行业指数无法算清内在价值时，"跌得多"≠安全边际；接飞刀不是价值投资 |
| 机会成本 | 现金是一种看涨期权 | 但长期拿着低收益现金也有成本，要比较"等好球"与"票息" |
| 有意义的底仓 | 看准了敢下重仓 | 不是机械小额试水，也不是一次性满仓，取决于赔率与确定性 |
| 长期持有 | 减少摩擦与择时错误 | 短期资金/有锁定期/高波动品种不适用 |

**写法要求**：不能只说"巴菲特会怎么做"，要写"巴菲特框架在这里的可用部分是什么、不适用部分是什么、因此本判断如何调整"。

## 五、输出样例（方法论表述，非推荐）

```
【现状】标的 X 近1月 -X.XX%，含转债敞口，持有期已满可赎
【证据】同池近1月排名前 d.d%，绝对值为负
【为何考虑】初买理由"利率下行利好债基"部分成立
【反证】含转债使其跟随权益波动；真跌市中与纯债不同步；不应把"债"当避风港
【摩擦】赎回费 0（已满持有期），在途 1–2 天
【置信度】中；失效条件：若权益企稳且转债回升，该逻辑反向
【信号】入场三信号未全达标 → 暂不新增
【边界】以上为方法论与数据整理，不构成投资建议；最终决策与风险由使用者自行承担，数据以自行核实为准。
```
